# Glossary

Prado terms used throughout this guide, in alphabetical order.

Affix
:   A bonus stat on an item, either a Prefix or a Suffix. See [Stats](../gearing-up/stats.md).

Arena
:   Where players compete in 3v3 matches for rank and Marks of Valor. Ends Lone Wolf status. See [Where to Get Gear](../gearing-up/sources.md#arena).

Attribute required
:   How much of an attribute (Strength, Dexterity, or Intellect) you need to equip an item.

Attunement
:   One roll when enchanting. Spend it to reroll an affix or its value. See [Rarity](../gearing-up/rarity.md#what-are-attunements).

Back line
:   The two rear slots in your party's formation. Safer from melee, but melee attacks from there deal 35% less damage. See [Combat](../combat/index.md#back-line).

Barrier
:   A shield that absorbs damage before your health, starting full each fight. See [Combat](../combat/index.md#barrier).

Block
:   Cuts an attack's damage in half. See [Combat](../combat/index.md#hitting-missing-and-blocking).

Copper, Silver, Gold
:   Prado's currency. 100 Copper is 1 Silver, and 100 Silver is 1 Gold. See [Economy](../economy/index.md).

Crystal
:   A material used in every crafting recipe. Gear professions each use one type. See [Crafting](../crafting/index.md#crystals).

Draw
:   When both sides are defeated at once. Counts as a loss in adventure decks. See [Combat](../combat/index.md#how-a-fight-plays-out).

Epic
:   An extremely rare tier with unlimited attunements. Can't be farmed. See [Rarity](../gearing-up/rarity.md#epic).

Essence
:   The material spent when enchanting. Which one you need depends on the item's level. See [Enchanting](../enchanting/index.md#essences).

Fatigue
:   Growing damage everyone takes once a fight passes 40 seconds. See [Combat](../combat/index.md#fatigue).

First craft bonus
:   Double experience the first time you craft any recipe. See [Crafting](../crafting/index.md#leveling-a-profession).

Formation
:   Your party's 2x2 grid of front line and back line slots. See [Combat](../combat/index.md#formations).

Friend code
:   A code from another player that gets you a free ring at character creation. See [Character Creation](../character-creation/index.md).

Front line
:   The two forward slots in your party's formation. The only slots enemy melee attacks can reach. See [Combat](../combat/index.md#front-line).

Imbuing
:   Raising an item's rarity by one tier, up to Rare. Costs a shard and crafting materials. See [Enchanting](../enchanting/index.md#imbuing).

Item level
:   The level of the item itself. It determines which essence and shard the item needs.

Legacy
:   The server that runs one season behind Seasonal. See [Character Creation](../character-creation/index.md#seasonal-or-legacy).

Lone Wolf
:   An optional challenge status, lost when you interact with other players. See [Character Creation](../character-creation/index.md#lone-wolf-optional).

Looking for Party
:   A setting in the Friends menu that lets anyone invite you to a party. See [Parties](../parties/index.md#forming-a-party).

Mailbox
:   Where Trading Post items and gold are delivered. See [Economy](../economy/index.md#mailbox).

Mana Loop
:   The Priest and Magician synergy between Prayer of Healing and Arcane Infusion. See [Parties](../parties/index.md#the-mana-loop).

Marks of Valor
:   Arena currency used to buy special Unique items. See [Where to Get Gear](../gearing-up/sources.md#arena).

Prefix
:   One of the two affix types. See [Stats](../gearing-up/stats.md).

Required level
:   The character level needed to use or equip an item.

Rest
:   Healing in town for money. The cost rises as the game goes on. See [Economy](../economy/index.md#what-money-is-for).

Seasonal
:   The server with the latest updates. See [Character Creation](../character-creation/index.md#seasonal-or-legacy).

Shard
:   The material that imbuing requires, matched to the item's level. Comes from disenchanting. See [Enchanting](../enchanting/index.md#imbuing).

Skill level
:   The profession level needed to craft a recipe.

Socketed
:   A Common-grade item with built-in sockets. The base for the endgame path. See [Rarity](../gearing-up/rarity.md#socketed).

Suffix
:   One of the two affix types. See [Stats](../gearing-up/stats.md).

Trading Post
:   Where players buy and sell with each other. Ends Lone Wolf status. See [Economy](../economy/index.md#trading-post).

Unique
:   A tier of items that come as-is, often with special effects. See [Rarity](../gearing-up/rarity.md#unique).

Unique Monster
:   A waystone monster that drops 1 to 3 pieces of gear. See [Parties](../parties/index.md#party-size-and-gear-drops).

Unique Treasure
:   A waystone treasure that gives each player a random item. See [Regions](../waystones/regions/index.md).

Vita
:   The energy you spend to play, earned by walking. See [Core Concepts](../getting-started/core-concepts.md#vita).

Waystone
:   Endgame content made up of decks in each region. See [Waystones](../waystones/index.md).
