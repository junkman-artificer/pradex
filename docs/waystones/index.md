# Waystones

Waystones are Prado's end-game PvE. Here's the short version: you combine three runes into a waystone, use it to start a tougher deck in one of five regions, and walk away with better loot and better runes to do it all again.

## Getting started

1. Finish the final deck in Ravenspire Tower, up in Icetooth Base Camp. That unlocks Runecrafting.
2. From then on, monsters in Ravenspire Tower start dropping runes.
3. Combine 3 runes and 1 Vita to make a waystone.
4. Use the waystone to start its deck. That's it!

## Runes

Every rune has three things going on:

- **Type** decides which deck you get. Flower Rune + City Rune + any other rune makes Festival of Petals, for example, which runs in Sweetwater.
- **Tier** decides how hard (and how rewarding) the deck is. Each tier adds +3 to the item level of what drops, and clearing a deck hands you higher-tier runes to keep climbing.
- **Modifiers** come in three flavors: **Fortunes** add rewards (like Item Drop Rate), **Omens** make things harder (like more monster health), and **Card Modifiers** add specific cards (like +1 Shrine). Everything on all three runes stacks onto the waystone, so the trick is finding a combo that's rewarding without being brutal.

Not sure which runes make which waystone? The [Runecrafting Combinations](https://runecrafting.netlify.app/){ target="_blank" } site has every combination.
